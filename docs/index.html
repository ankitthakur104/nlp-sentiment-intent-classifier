🏗Model Architecture

Raw Text → BertTokenizerFast → bert-base-uncased ↓ Fine-tune (3 epochs) Multi-label Head (8 outputs) ↓ sigmoid + threshold=0.5 Intent Labels + Sentiment Labels → FastAPI Batch API

✨Key Features

Fine-tuned BERT

bert-base-uncased fine-tuned for 3 epochs using HuggingFace Trainer with warmup scheduling.

Multi-label Classification

Simultaneously predicts 5 intent labels (refund, support, billing, complaint, info) + 3 sentiment labels.

200K+ Training Data

Trained on labeled customer support tickets with balanced class weighting for rare intents.

Batch Inference API

FastAPI endpoint processes lists of texts in a single forward pass — efficient at scale.

Confidence Scores

Returns per-label sigmoid probabilities alongside predicted classes for downstream routing.

Docker Deployment

Containerized with model weights, tokenizer, and FastAPI server — ready for K8s deployment.

💻Inference API Code

LABELS = ["refund","tech_support","billing","complaint","info",
            "positive","negative","neutral"]

  @app.post("/classify")
  def classify(req: TextRequest):
      enc = tokenizer(req.texts, truncation=True, padding=True,
                      max_length=128, return_tensors="pt")
      with torch.no_grad():
          logits = model(**enc).logits
      probs  = torch.sigmoid(logits).numpy()   # multi-label
      preds  = (probs > req.threshold).astype(int)
      return {
          "predictions": [
              {"text": t,
               "labels": [LABELS[j] for j,p in enumerate(row) if p],
               "scores": dict(zip(LABELS, probs[i].tolist()))}
              for i,(t,row) in enumerate(zip(req.texts, preds))
          ]
      }
